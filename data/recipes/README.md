# 요리 데이터

총 2,100개: 한식 560 · 중식 220 · 일식 250 · 양식 599 · 동남아 140 · 인도 130 · 기타 201.

- 기존 1,000개 메뉴의 ID를 보존하고 1,000개를 추가했습니다. 요리명 오기·유사 메뉴·권역·주재료와 양념 분류를 검토하고 교정했습니다.
- 생소한 이름은 `가보차니모노(단호박 조림)`처럼 한글 설명을 붙였습니다. 설명도 검색 대상입니다.
- 주재료 721종, 양념·소스 236종을 등록했습니다. 표기 기준의 개수이며 서로 완전히 다른 재료의 개수를 의미하지 않습니다.
- 한식에 60개를 추가했습니다. 밥·면 10종, 국·탕·냉국 10종, 고기·해산물 요리 10종, 채소·두부·묵 반찬 10종, 김치·장아찌 10종, 떡·부각·간식 10종으로 재료와 조리법의 폭을 넓혔습니다. 각 메뉴에 대표 재료·양념과 추정 맛 강도를 입력했습니다.
- 기타식에 퓨전·이색 메뉴 40개를 추가했습니다. 참소스·초장·쌈장·불닭소스 등을 활용한 요리와 고수김치·수박껍질김치·아보카도장·김치 땅콩버터 비빔면처럼 색다른 조합을 포함합니다. 퓨전 메뉴는 전통 음식의 권역을 단정하지 않고 `other`로 분류하며, 기존과 같이 첫 주재료로 묶습니다.
- `초장`과 `초고추장`은 같은 소스로 검색됩니다. 신규 메뉴의 맛 강도 역시 재료 조합에 따른 편집 추정치입니다.
- JSON은 요리권역 → 첫 번째 주재료 → 요리 목록 구조입니다. ID는 전역 고유 값입니다.
- 같은 메뉴의 표기·별칭·제공자·담는 그릇 차이로 항목을 늘리지 않았습니다. 독립된 메뉴로 통용되는 조리 방식과 재료 변형은 별도 항목입니다.
- 재료·양념은 메뉴 탐색용 대표 구성입니다. 지역·가정별 조리법에 따라 달라지며, 전체 조리법을 제공하는 데이터가 아닙니다. 맛 태그도 대표적인 특징을 나타냅니다.
- 외부 레시피 본문이나 사진, 외부 데이터셋을 복사·재배포하지 않았습니다.

## 맛 강도

각 요리의 `flavors`는 검색 태그를 유지하며, `flavorLevels`는 같은 맛 ID를 키로 사용하는 1~5 정수입니다. 예: `"flavorLevels": { "spicy": 3, "umami": 4 }`. 별은 평점이 아니라 해당 맛의 예상 강도입니다. 1은 은은함, 3은 보통, 5는 매우 강함을 뜻합니다. 태그가 없는 맛은 0점이 아니라 미등록입니다.

전체 메뉴의 초기값은 재료·양념·메뉴명에 따른 편집용 규칙으로 설정한 추정치입니다. 실측·시식 결과가 아니며 실제 강도는 양념 분량과 조리법에 따라 달라집니다. `scripts/seed-flavor-levels.ts`에 초기 규칙이 있으며, 이미 입력된 값은 보존합니다. 검토 후 JSON에서 메뉴별 수치를 직접 조정하세요. 런타임은 강도를 추론하지 않고 저장된 값을 표시합니다. 기존 강도가 없는 데이터도 읽을 수 있지만, 현재 원본 2,100개에는 모두 값을 입력했습니다.

빌드와 브라우저 로더는 등록된 맛과 강도 키의 일치, 정수 여부, 1~5 범위를 검증합니다.
