# 요리 데이터

총 2,000개: 한식 500 · 중식 220 · 일식 250 · 양식 599 · 동남아 140 · 인도 130 · 기타 161.

- 기존 1,000개 메뉴의 ID를 보존하고 1,000개를 추가했습니다. 요리명 오기·유사 메뉴·권역·주재료와 양념 분류를 검토하고 교정했습니다.
- 생소한 이름은 `가보차니모노(단호박 조림)`처럼 한글 설명을 붙였습니다. 설명도 검색 대상입니다.
- 주재료 704종, 양념·소스 225종을 등록했습니다. 표기 기준의 개수이며 서로 완전히 다른 재료의 개수를 의미하지 않습니다.
- JSON은 요리권역 → 첫 번째 주재료 → 요리 목록 구조입니다. ID는 전역 고유 값입니다.
- 같은 메뉴의 표기·별칭·제공자·담는 그릇 차이로 항목을 늘리지 않았습니다. 독립된 메뉴로 통용되는 조리 방식과 재료 변형은 별도 항목입니다.
- 재료·양념은 메뉴 탐색용 대표 구성입니다. 지역·가정별 조리법에 따라 달라지며, 전체 조리법을 제공하는 데이터가 아닙니다. 맛 태그도 대표적인 특징을 나타냅니다.
- 외부 레시피 본문이나 사진, 외부 데이터셋을 복사·재배포하지 않았습니다.
