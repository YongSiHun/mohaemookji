# UI 디자인 컨벤션

홈 검색, 요리 카드, 요리 상세, 서비스 안내에 적용하는 공통 기준입니다. 구현 토큰은 [design-system.css](../src/styles/design-system.css), 컴포넌트 배치는 [index.css](../src/index.css)에서 관리합니다.

## 글씨 계층

크기는 역할로 선택합니다. 같은 역할을 화면마다 다르게 지정하지 않습니다. CSS 변수는 rem 단위로 정의하고, 아래 px 값은 브라우저 기본 글자 크기 16px 기준입니다.

| 역할                | 토큰                   | PC           | 모바일 ≤600px | 적용 예                                      |
| ------------------- | ---------------------- | ------------ | ------------- | -------------------------------------------- |
| 브랜드 소개         | `--text-display`       | 36~62px 유동 | 최소 36px     | 홈의 “오늘 뭐해 먹지?”                       |
| 페이지 제목         | `--text-page-title`    | 40px         | 32px          | 요리명, 서비스 소개·약관 제목                |
| 섹션 제목           | `--text-section-title` | 28px         | 24px          | 맛·재료 질문, 메뉴 후보, 상세 h2             |
| 소제목·카드 제목    | `--text-subtitle`      | 22px         | 20px          | 요리 카드명, 맛 그룹, 재료·양념 제목         |
| 선택 항목·필드 라벨 | `--text-label`         | 18px         | 18px          | 맛 이름, 추천 검색어 제목·항목, 상세 맛 정보 |
| 도입 설명           | `--text-lead`          | 18px         | 18px          | 홈 소개, 요리 소개                           |
| 본문                | `--text-body`          | 16px         | 16px          | 요리 설명, 재료, 조리 순서, 안내 본문        |
| 보조 설명           | `--text-helper`        | 14px         | 14px          | 입력 도움말, 적용 조건, 맛 강도 안내, 푸터   |
| 메타·캡션           | `--text-caption`       | 12px         | 12px          | 권역·분류, 사진 출처, 단계 번호, 강도 숫자   |
| 주요 동작           | `--text-action`        | 18px         | 18px          | 검색, 더 보기, 재시도, 유튜브 이동           |
| 검색 입력           | `--text-input`         | 20px         | 18px          | 재료 검색 입력·placeholder                   |

로고 글자는 `--text-brand`(34/28px)로 별도 관리합니다. 아이콘·별은 문자 크기 계층에 포함하지 않으며 `--icon-*` 토큰을 사용합니다. 별의 숫자는 맛의 예상 강도이지 평점이 아닙니다.

## 굵기와 줄 간격

- 페이지·섹션 제목: `--weight-heading`(800), 소제목·라벨·주요 동작: `--weight-strong`(700).
- 짧은 강조·메타: `--weight-medium`(600), 기본 본문: `--weight-regular`(400). 브랜드 전용 서체의 굵기는 400을 유지합니다.
- 제목: `--leading-heading`(1.4), 본문: `--leading-body`(1.75), 보조 설명: `--leading-helper`(1.6), 입력·버튼: `--leading-control`(1.5).
- h1/h2/h3는 문서 구조에 맞춰 사용합니다. 제목처럼 보이는 폼 label도 같은 시각 계층 토큰을 사용하며 label 연결은 유지합니다.
- 입력창은 위아래 패딩을 동일하게 둡니다. 좌우 패딩을 달리할 때 네 값을 명시합니다. 현재 입력 높이는 PC 76px·모바일 68px입니다.

## 간격과 색상

- 기본 간격: `--space-1`부터 `--space-8`까지 4·8·12·16·24·32·40·48px입니다. 관련 문구 사이는 8~12px, 설명과 다음 동작 사이는 24px를 기본으로 합니다.
- 텍스트는 `--color-text`, 보조 본문은 `--color-supporting`, 메타는 `--color-muted`를 사용합니다.
- 주요 동작·선택 강조는 `--color-action`, hover는 `--color-action-hover`를 사용합니다. 브랜드의 주황색과 본문의 갈색·크림 계열은 유지합니다.
- 바탕·카드·구분선은 `--color-canvas`, `--color-surface`, `--color-border`를 사용합니다. 꾸밈에 필요한 옅은 색조는 컴포넌트에 둘 수 있습니다.

## 반응형과 조작

- 최소 지원 너비는 320px이며, 높이는 콘텐츠에 따라 늘어납니다. 모바일에서 본문·선택 항목을 작게 축소하지 않습니다.
- 글씨 크기의 모바일 전환은 design-system.css의 600px 조건 한 곳에서 관리합니다. 개별 컴포넌트의 미디어 쿼리는 배치·간격만 조정합니다.
- 제목은 단어 단위로 줄바꿈하고, 긴 메뉴명·출처·검색어는 필요한 경우 줄 안에서 나눕니다. flex/grid 자식은 `min-width: 0`을 사용합니다.
- 맛 카드는 PC 4열, 중간 화면 2열, 모바일 1열입니다. 420px 이하에서는 이름과 별을 위아래로 쌓습니다.
- 별 선택·강도 무관·새로고침·검색어 지우기는 최소 44px 높이를 확보합니다. 적용 조건·추천 검색어는 화면 너비 안에서 줄바꿈합니다.
- 별 선택 상태는 색상과 채워진 별, 강도 숫자로 함께 보여줍니다. 키보드 포커스와 접근성 이름을 유지합니다.

## 수정 규칙

1. 새 UI는 먼저 위 표에서 역할을 고르고 `font-size: var(--text-...)`로 지정합니다. 컴포넌트에 px/rem 크기를 추가하지 않습니다.
2. 같은 역할의 크기를 바꿀 때 design-system.css의 토큰을 수정합니다. 특정 화면의 CSS 뒤에 덮어쓰는 규칙을 붙이지 않습니다.
3. 새 계층이 정말 필요한 경우 이 문서와 토큰을 함께 갱신합니다. 브랜드·별·장식 아이콘 예외도 이름 있는 토큰으로 남깁니다.
4. 320·390·600·768·1120px에서 홈, 선택 상태, 긴 검색어, 요리 카드, 상세, 서비스 안내를 점검합니다. 확대된 글자와 긴 메뉴명, 키보드 조작도 확인합니다.
